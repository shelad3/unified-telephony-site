How to install

  1. Download the APK to your phone (or open this page on your phone).
  2. Tap the file when the download finishes.
  3. If asked, allow your browser to install unknown apps, then confirm.
  4. After the first install, set Unified Telephony as your phone/SMS app when prompted.
